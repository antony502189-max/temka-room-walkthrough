# Комната — прогулка в 3D

[Открыть комнату](https://antony502189-max.github.io/temka-room-walkthrough/)

Осматривайте интерьер прямо в браузере: WASD/стрелки — ходьба, перетаскивание — взгляд,
«Управлять мышью» — свободный поворот, Esc — освободить курсор.
Четыре точки обзора, мини-план, помощь, общий осмотр без потолка и возврат в начало.
Стены и закрытые двери ограничивают движение; двери статичны.

Для просмотра не нужны установка, Blender, сервер и учётная запись.
Можно также скачать docs/index.html и открыть локально: код, модель и текстура встроены.

## Сборка

```sh
npm ci
npm test
npm run build
```

Проверено с Node.js 24.22.1. Точные версии зависимостей закреплены в package-lock.json.
Сборка обновляет docs/index.html (GitHub Pages), artifacts/room-walkthrough.html
(автономный файл) и dist/index.html. Эти файлы содержат одинаковые байты.
После изменения исходников пересоберите и закоммитьте docs/index.html.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /docs.
Файл docs/.nojekyll отключает обработку Jekyll. Публикуется только docs/.

## Файлы

- source/temka.blend — оригинальная модель, сохранена без изменений.
- assets/room_web.glb — модель для браузера со встроенной текстурой.
- assets/navigation.json — готовая область ходьбы с учтённым радиусом игрока.
- src/ — просмотрщик Three.js, контроллер и запасной Canvas2D-рендерер.
- tools/ — подготовка модели, диагностика/установка Blender на Mac, упаковка.
- tests/ — 21 автоматический тест.

Не увеличивайте препятствия на радиус игрока повторно. При изменении геометрии
нужно пересчитать навигацию. Для просмотра исходный Blender не требуется.

## Проверка

На Apple M2 Pro, macOS 26.7.2, Chrome for Testing 157.0.8103.38 проверены WebGL2,
открытие file:// без сети, ходьба, столкновения, ракурсы, обзор, интерфейс,
системный Esc и смена вкладки. На локальном тесте ходьбы/вращения медиана кадра
8.3 мс, p95 9.3 мс при окне 1440×900 и DPR=2.
Safari, настоящий телефон и ручные жесты физического трекпада не проверены.
В Canvas2D качество освещения упрощено. Лицензия Three.js встроена в HTML.
